# Support Policy

## Compatibility

- Go: the version declared in `go.mod`
- Platforms: Linux amd64 is the primary production target; macOS and Windows remain development/test targets
- Browsers: current Chrome, Edge, Firefox, and Safari releases

## Support Window

- Latest release: full support
- Previous release: security fixes only, when feasible
- Older releases: unsupported

## Stability Tiers

- Library packages (`stack`, `queue`, `list`, `counter`, `ringbuffer`): stable public APIs unless noted in release notes
- Web service and deployment assets: production-oriented but still evolving; breaking operational changes must be documented in release notes
